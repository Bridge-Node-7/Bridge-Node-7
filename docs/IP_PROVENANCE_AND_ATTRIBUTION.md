# IP Provenance and Attribution

Bridge Node 7 publishes selected public reference implementations so they can be
inspected and evaluated without exposing the private institutional systems,
customer material, unpublished research, or other nonpublic assets that are not
part of those releases.

This document identifies the **authoritative public origin** of Bridge Node 7
GitHub work and clarifies the boundary between public availability, repository
licensing, attribution, and official Bridge Node 7 releases.

## Canonical public origin

The authoritative upstream for a Bridge Node 7 public GitHub repository is the
repository under:

`https://github.com/Bridge-Node-7/`

Use the exact repository URL, commit SHA, and—when available—tagged GitHub
Release when identifying or citing a version.

A third-party fork, mirror, archive, modification, redistribution, or derivative
is **not** an official Bridge Node 7 release unless Bridge Node 7 explicitly says
otherwise.

## Repository terms control

Public availability is not a transfer of authorship, source identity, brand
rights, or rights beyond those granted by the applicable repository terms.

Each repository's own `LICENSE`, `NOTICE`, `CITATION.cff`, and release
documentation control for that repository and version. Where a repository
permits reuse, the permissions and preservation/attribution obligations in that
license continue to apply.

Current public surfaces intentionally use different licensing postures because
they serve different purposes. Do not infer one repository's permissions from
another repository.

## Attribution and provenance

Git history, commit identities, release timestamps, release manifests,
checksums, citations, and provenance attestations—where present—form part of the
public provenance record.

Removing Bridge Node 7 branding from a lawful derivative does not convert the
underlying public history into evidence of different origin, and permissive
reuse does not authorize a third party to misrepresent an official Bridge Node 7
release, endorsement, or source.

## Brand boundary

Software and documentation licenses do not grant a general right to use Bridge
Node 7 names, marks, logos, website identity, or visual identity as branding for
a third-party product or service unless the applicable terms expressly say so.

Reasonable references needed to identify source or satisfy a license remain
subject to the applicable license and law.

## Reporting suspected misattribution

Suspected false-origin claims, misleading redistribution, or misuse of Bridge
Node 7 source identity may be reported privately to:

`contact@bridgenode7.com`

Include the third-party URL, the Bridge Node 7 source URL, and the exact
commit/tag/release involved when possible.

## Boundary

This document is a public provenance and attribution statement, not legal
advice, a patent claim, a trademark-registration claim, or a representation
that every public repository uses the same license.
