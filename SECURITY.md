# Security Policy

Bridge Node 7 treats security reports as private review material.

## Reporting

Report a suspected vulnerability through the canonical security contact:

- Email: contact@bridgenode7.com
- Subject: Bridge Node 7 Security Report
- Canonical security contact: https://bridgenode7.com/.well-known/security.txt

Please do not open a public issue for a vulnerability.

Provide the minimum information needed to reproduce and understand the issue. Do not send classified, export-controlled, customer-confidential, credential, medical, or other sensitive third-party material through the public reporting channel.

## Scope

This repository is the public Bridge Node 7 institutional profile and reference index. Individual Bridge Node 7 repositories may publish their own SECURITY.md with project-specific scope and handling guidance; those repository-local policies govern reports for those projects.

A report, acknowledgement, test result, or remediation does not establish broader certification, authorization, or operational readiness.

## Disclosure

Do not publicly disclose an unresolved vulnerability in a way that increases exploitation risk. Bridge Node 7 will evaluate reports within the authority and evidence available for the affected surface.

This policy does not create a bug-bounty program, payment commitment, service-level agreement, or authorization to test systems you do not own or have permission to test.
